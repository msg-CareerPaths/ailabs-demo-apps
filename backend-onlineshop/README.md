# Online Shop API

A small-scale e-commerce backend application built with Spring Boot.

## Documentation

- [Project Overview](./docs/PROJECT.md) — user roles, features, and application scope
- [Backlog](./docs/BACKLOG.md) — remaining work items by complexity

## Setup

- Clone the repository
- Create your own personal repository and clone it locally
- Copy **only** the folder which contains the app (`backend-onlineshop/`)
- Push the changes
- Start your [database](./docker/development/docker-compose.yml)
- Bootstrap the [API](./onlineshopapi/README.md)
- Test the API using [Swagger UI](http://localhost:3000/api/swagger-ui/index.html) or Postman
